# 광주 졸업식 일정 도우미

광주 지역 **초·중·고·대학교·전문대학의 졸업식 일정**을 조사하고, 직접 확인한 내용을 보완해 **오프라인 HTML 일정표**로 보관하는 로컬 웹 프로그램입니다.

내부 AI Agent가 부족한 정보를 찾기 위한 검색·문서 읽기·조사 종료를 결정합니다. 수집한 날짜·시간·인원은 근거를 검사해 제공하고, 근거와 수정 이력은 PC에 저장합니다.

## 시작하기

**macOS, Python 3.11~3.13, 인터넷 연결**이 필요합니다. 프로젝트 폴더에서 처음 한 번 설치합니다.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install --no-deps -e .
```

[.env.example](.env.example)을 복사해 `.env`를 만들고 자료원 키를 입력합니다. 기존 `.env`가 있다면 덮어쓰지 마세요.

| 설정 | 용도 |
|---|---|
| `NEIS_API_KEY` | 학교 목록·학사일정 조회 |
| `SCHOOLINFO_API_KEY` | 학교알리미 학년별 학생 수 조회 |
| `TAVILY_API_KEY` | 공식 안내를 찾기 위한 웹 검색 |

사용할 모델은 둘 중 하나만 준비합니다.

- **Ollama:** `.env`의 `LLM_BACKEND=ollama`를 유지합니다. [Ollama](https://ollama.com/download)를 설치·실행하고 `ollama pull qwen3:8b`로 기본 모델을 받습니다.
- **OpenAI:** `LLM_BACKEND=openai`로 바꾸고 `OPENAI_API_KEY`를 입력합니다. 공식 문서의 필요한 텍스트가 OpenAI로 전송됩니다.

키 발급·모델 변경·선택적 LangSmith 추적은 [설정 안내](config/README.md)를 참고하세요. 준비가 끝나면 **[start.command](start.command)를 더블 클릭**합니다. 브라우저에 프로그램 화면이 열립니다.

## 사용 방법

1. 학교 목록이 없으면 **학교 목록 불러오기**를 누릅니다.
2. **조사 기간 선택**에서 찾을 졸업식의 시작일·종료일을 선택하고 **조사 시작**을 누릅니다. 양끝 날짜를 포함하며 기간은 6개월 미만입니다. 시즌이 이미 있으면 **새 시즌 조사**로 다른 기간을 추가하고, 기존 기간은 **저장된 시즌 → 이 시즌 다시 조사**로 갱신합니다.
3. 날짜가 확인됐지만 시간이 비어 있는 학교는 **시간 찾기**를 누릅니다. 해당 시간 칸에 진행 상태와 결과가 나옵니다.
4. 전화·안내문으로 확인한 정보는 **직접 확인한 내용 → 기록하기**로 보완합니다. 학교·날짜·시간·확인 방법·실제 확인시점을 적으면 기존 기록에 연결하고, 모호하거나 충돌하는 부분은 추가로 질문합니다.
5. **일정표 열기**로 최신 HTML을 보거나 **파일 내려받기**로 사본을 받습니다. 사용을 마치면 하단의 **프로그램 종료**를 누릅니다.

시즌이 없으면 기간 선택 화면을 보여 줍니다. 앱을 실행하거나 학교 목록을 불러오는 것만으로 시즌이 생성되지는 않습니다.

기본 조사는 전체 대상 학교의 날짜·인원을 찾고, 같은 자료에 명시된 본식 시간도 함께 저장합니다. 학교명·구·날짜 필터는 표시만 바꾸며 조사 범위를 줄이지 않습니다. 직접 기록한 값은 자동 조사가 임의로 덮어쓰지 않습니다.

진행 중인 조사는 잠시 멈추고 이어갈 수 있습니다. 브라우저 창을 닫는 것만으로는 프로그램이 종료되지 않으며, 입력창의 문장은 **기록하기**를 눌러야 저장됩니다.

## 일정표 보기

기록과 기간별 HTML은 **자동 저장·갱신**됩니다. **내려받은 사본은 자동 갱신되지 않으므로**, 추가 조사나 직접 기록 후에는 다시 내려받으세요.

파일명 예: `광주 졸업식 일정표 (2025.12.01~2026.03.31).html`

- 내려받은 HTML은 프로그램과 인터넷 없이 검색·필터·페이지 이동·인쇄가 됩니다. 새 조사와 직접 기록은 실행 중인 프로그램에서 합니다.
- 학교명·구·날짜 조건을 함께 적용하며 **20행씩** 표시합니다. **인쇄**는 조건에 맞는 전체 행을 출력합니다.
- 학교명을 누르면 공식 홈페이지가 열립니다. 홈페이지 방문에는 인터넷이 필요합니다.

| 항목 | 읽는 방법 |
|---|---|
| 공란 | 현재 확인해 제공할 수 있는 값이 없습니다. 미발견·접근 실패가 정보 미공개를 뜻하지는 않습니다. |
| 졸업인원수 | 초중고는 해당 학년도 졸업 학년 재학생 수, 대학은 확인된 졸업인원입니다. 실제 참석 인원과 다를 수 있습니다. |
| 장소 | 확인된 학교·캠퍼스 주소입니다. 실제 졸업식 장소를 확정한 값은 아닙니다. |

학교 사이트의 접근 제한이나 이미지·HWP 등 지원하지 않는 형식 때문에 빈칸이 남을 수 있습니다. 필요한 정보는 학교에 직접 확인해 보완하세요.

## 기록 보관

기본 저장 위치는 DB `data/live/graduation.sqlite3`, 자동 저장 HTML `data/live/exports/`입니다. **관리 → 기록 백업**으로 DB 사본을 받을 수 있습니다. `.env`와 `data/`에는 비밀 설정·개인 기록이 있으므로 공유하거나 Git에 올리지 마세요.

조사 취소는 이미 저장한 결과를 지우지 않습니다. 처음부터 다시 조사하려면 [기록 초기화 안내](docs/RESET_RESEARCH_DATA.md)를 따르세요. 초기화는 백업 후 **저장된 시즌·기간과 모든 조사·직접 기록을 삭제**하며 학교 목록·설정은 유지합니다. 다시 실행한 뒤 조사할 기간을 선택하세요.

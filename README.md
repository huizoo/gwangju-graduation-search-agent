# 광주 졸업식 일정 도우미

광주 지역 **초등학교·중학교·고등학교·대학교·전문대학**의 졸업식 날짜·시간·인원을 조사하는 **AI Agent 기반 로컬 웹 프로그램**입니다. 공식 자료를 조사하고 직접 확인한 내용을 기록해, 프로그램 없이도 열어볼 수 있는 HTML 일정표를 만듭니다.

AI Agent는 부족한 정보를 찾기 위해 검색·문서 읽기·추가 조사 여부를 결정합니다. 확인한 근거는 코드로 다시 검사하며, 확인하지 못한 값은 추측해서 채우지 않습니다. 조사 결과와 수정 이력은 PC의 SQLite DB에 저장됩니다.

## 실행 준비

Python 3.11~3.13 환경에서 프로젝트 폴더를 열고 한 번 설치합니다.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install --no-deps -e .
```

`.env.example`을 참고해 `.env`에 NEIS·학교알리미·Tavily 키와 모델 연결을 준비합니다. 기존 `.env`가 있으면 유지하세요. `LLM_BACKEND`로 Ollama 또는 OpenAI를 선택하며, 장애 시 다른 백엔드로 자동 전환하지 않습니다. Ollama는 설치한 모델을 실행하고, OpenAI는 API 키를 준비합니다. 세부 항목은 [설정 안내](config/README.md)에 있습니다. 키를 Git에 올리지 마세요.

## 사용 방법

**[start.command](start.command)를 더블 클릭**하면 브라우저에서 프로그램이 열립니다.

1. 학교 목록이 없으면 **학교 목록 불러오기**를 누릅니다.
2. **새 시즌 조사**에서 찾을 졸업식의 시작일·종료일을 선택합니다. 양끝 날짜를 포함하며, 기간은 6개월 미만입니다.
3. **조사 시작**을 누릅니다. 전체 대상 학교의 날짜와 인원을 찾고, 같은 원문에 명시된 본식 시간도 함께 기록합니다.
4. 시간이 비어 있는 학교는 **시간 찾기**를 누릅니다. 해당 칸에서 진행 상태와 결과를 확인할 수 있습니다.
5. 전화나 안내문으로 확인한 내용은 **직접 확인한 내용**에 적고 **기록하기**를 누릅니다. 예: “○○초 졸업식은 1월 6일 오전 10시래. 방금 학교에 전화해서 확인했어.” 애매하거나 기존 기록과 충돌하면 추가 질문이 나옵니다.
6. **일정표 열기**로 결과를 확인하거나 **파일 내려받기**로 HTML을 받습니다.
7. 사용을 마치면 **프로그램 종료**를 누릅니다. 진행 중인 조사는 멈추고, 다음 실행에서 이어갈 수 있습니다. 입력창에만 남은 문장은 먼저 기록하세요.

이미 조사한 기간은 **저장된 시즌 → 이 시즌 다시 조사**로 갱신합니다. 기존 기록과 직접 확인한 값은 유지됩니다. 구·학교명·날짜 필터는 표의 표시만 바꾸며 조사 범위를 줄이지 않습니다.

## 일정표 읽기와 저장

표에는 **날짜 · 학교명 · 시간 · 졸업인원수 · 장소**가 나옵니다. 학교명은 공식 홈페이지로 연결됩니다. 장소는 확인한 학교·캠퍼스 주소이며 실제 행사장이라는 뜻은 아닙니다.

- **공란**은 현재 확인해 제공할 수 있는 값이 없다는 뜻입니다. 자료 접근 실패나 미발견을 미공개로 단정하지 않습니다. 취소·미실시가 확인되면 짧게 표시합니다.
- 초중고 인원은 해당 행사 학년도의 **졸업 학년 재학생 수**일 수 있습니다. 대학은 확인된 졸업인원을 사용합니다. 실제 참석 인원과 다를 수 있습니다.
- 검색·구·날짜 조건을 함께 적용하고 20행씩 봅니다. **인쇄**는 조건에 맞는 전체 행을 출력합니다.

기록과 기간별 HTML은 **자동 저장**됩니다. 파일 이름은 `광주 졸업식 일정표 (2025.12.01~2026.03.31).html` 형식입니다. 내려받은 HTML의 검색·필터·페이지 이동·인쇄는 프로그램과 인터넷 없이 작동합니다. 학교 홈페이지를 열 때에는 인터넷이 필요합니다.

다른 곳에 내려받은 복사본은 자동 갱신되지 않습니다. 추가 조사 후에는 다시 내려받으세요.

## 기록 보관

DB는 `data/live/graduation.sqlite3`, 자동 갱신 HTML은 `data/live/exports/`에 있습니다. **관리 → 기록 백업**으로 DB 복사본을 `data/live/backups/`에 보관할 수 있습니다. **학교 목록 갱신**도 관리에서 실행합니다. `.env`와 `data/`에는 개인 설정·기록이 있으므로 공유하지 마세요.

조사 기록을 처음부터 다시 만들려면 앱의 **프로그램 종료**를 누르고 **[reset-research.command](reset-research.command)를 더블 클릭**하세요. 안내를 확인하고 `초기화`를 입력하면 전체 DB와 자동 저장 HTML을 백업한 뒤 **모든 시즌의 조사·직접 기록을 비웁니다.** 학교 목록·설정·저장된 기간은 유지합니다. DB 파일을 직접 삭제하지 마세요. 취소한 조사의 저장 결과도 남으므로, 조사 취소와 기록 초기화는 다른 동작입니다.

학교 사이트의 접근 제한, 이미지·HWP 등 지원하지 않는 자료 형식에 따라 조사가 끝나도 빈칸이 남을 수 있습니다. 직접 기록한 내용은 사용자가 확인한 진술로 보관하며, AI가 해석했다는 이유만으로 사실을 인증하지 않습니다.

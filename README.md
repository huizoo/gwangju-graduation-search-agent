# 광주 졸업식 일정 도우미

광주 5개 구 교육기관의 졸업식 **날짜와 실제 시작 시각**을 조사하고 근거·확인시점·보류 사유를 함께 제공하는 로컬 앱입니다. SQLite에 기록을 보관하며, 저장한 HTML은 앱과 인터넷 없이 열 수 있습니다.

## 실행

이 작업 폴더에 준비한 Python 3.11 가상환경을 사용합니다.

이 Mac에서는 **[start.command](start.command)를 더블 클릭**해도 됩니다.

```sh
cd $HOME/workspace/week15/gwangju-graduation-search-agent
source .venv/bin/activate
python -m app
```

브라우저가 자동으로 열립니다. 기본 주소는 `http://127.0.0.1:8600`이며 점유 중이면 사용 가능한 로컬 포트를 선택해 터미널에 표시합니다. 같은 저장소의 앱이 이미 실행 중이면 기존 화면을 엽니다.

새 컴퓨터의 개발 환경에서는 Python 3.11을 설치하고 다음을 먼저 실행합니다. Windows 실행파일 배포는 포함하지 않습니다.

```sh
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python -m app
```

## 어머니가 사용하는 순서

1. 보고 싶은 시즌과 기간을 선택합니다.
2. **기관 관리**에서 공식 목록을 가져오거나 관심 기관을 추가합니다. 목록의 범위와 기준일을 확인합니다.
3. **전체 기관 조사** 또는 기관을 선택해 조사합니다. 조사 도중에도 저장 기록을 보고 직접 입력할 수 있습니다.
4. **확인할 기관**에서 날짜·시각 누락과 근거를 확인하고, 전화나 문서로 직접 확인한 내용을 입력합니다. 실제 확인 시각을 모르면 비워 둡니다.
5. **판매 준비 가능**에서 날짜와 실제 시작 시각이 모두 현재 사용 가능한 행사만 봅니다.
6. **HTML 일정표 저장 → HTML 파일 내려받기**로 파일을 저장합니다. 저장된 파일을 더블 클릭하면 앱 없이 검색·필터·인쇄할 수 있습니다.
7. 종료할 때 **저장하고 프로그램 종료**를 사용합니다. 조사 중인 작업은 안전하게 멈추고 다음 실행에서 이어갈 수 있습니다. 취소한 작업은 다시 살아나지 않습니다.

HTML은 생성 당시의 사본이며 자동 갱신되지 않습니다. 최신 결과가 필요하면 앱에서 다시 조사하고 새 파일을 저장합니다. 근거 원문 링크를 열 때에는 인터넷이 필요합니다.

## 확인값과 기록의 차이

| 화면 | 표시 기준 |
| --- | --- |
| 일반 일정표 | 정당하게 확인한 일 단위 날짜와 그 날짜의 실제 시작 시각. 필요한 원문 재확인 실패 시 과거값과 경고를 함께 표시 |
| 판매 준비 가능 | 현재 사용 가능한 날짜와 같은 행사·날짜에 연결된 실제 시작 시각을 모두 충족 |
| 모든 기록·상세 | 후보, 월 계획, 확인시점 미상 수기, 충돌·기각·수정 이력 |

월만 아는 계획을 임의 날짜로 바꾸지 않습니다. 입장·등교·학위복 대여·하교 시각을 시작 시각으로 채우지 않습니다. 수기 기록은 자동 조사로 덮어쓰지 않으며, 수기와 공식 자료가 다르면 해당 항목을 다시 확인하게 합니다. 알림 읽음은 충돌 해결이 아닙니다.

## 설정과 기록 위치

- `.env`: 이 PC의 백엔드 선택·연결 정보·비밀키. 출력과 Git 추적에서 제외합니다.
- `config/defaults.json`: 비밀이 아닌 기본 설정과 새 시즌 기본값.
- `config/env-map.json`: 필요한 경우에만 사용하는 환경변수 덮어쓰기 목록.
- `data/live/graduation.sqlite3`: 실제 기록.
- `data/demo/`: 별도 데모 기록. 실제 자료와 자동으로 섞지 않습니다.
- `data/live/exports/`: 앱이 만든 읽기용 HTML 버전.
- `data/live/backups/`: 화면에서 생성한 SQLite 백업.
- `runtime/`: 개발 중 실제 연결·브라우저 검증 원시 산출물. Git에서 제외합니다.
- `docs/evidence/`: 검토한 검사 결과와 증빙.

`APP_DATA_DIR`를 지정하면 그 경로 아래 `live/` 또는 `demo/`를 사용합니다. 서버 실행 자산과 DB는 별도 경로에 있습니다. 기존 시즌은 SQLite가 관리하므로 설정의 새 시즌 기본값을 바꿔도 덮어쓰지 않습니다.

현재 `.env`는 Ollama를 선택합니다. Ollama 앱의 백그라운드 서비스와 설정한 모델을 준비해야 모델 후보 추출이 가능합니다. `LLM_BACKEND=openai`를 선택할 때만 OpenAI 키와 해당 모델 접근이 필요하며 다른 백엔드로 자동 전환하지 않습니다. OpenAI 선택은 공개 문서의 필요한 텍스트 전송을 허용하지만 명시적 `ALLOW_EXTERNAL_DOCUMENT_TEXT=false`가 우선합니다. 사적 메모와 이미지는 전송하지 않습니다.

NEIS·검색 키가 없거나 모델이 꺼져 있어도 저장 조회·직접 입력·HTML 저장은 사용합니다. 작업 도중 수집·모델·게시 설정이 달라지면 재개를 거절하며, 이전 설정 복원 또는 새 작업 생성을 안내합니다.

## 실제 확인한 결과

2026-10-20에 9개 유형의 대표 13기관을 조사했습니다. 현재 시즌은 **6기관의 날짜 10건**, 실제 시작 시각은 **0건**입니다. 시각을 임의로 채우지 않아 판매 준비 목록은 0건입니다. 별도 과거 GIST 공지의 **2026-02-20 14:00**은 실제 원문으로 검증했으며 올해 일정으로 사용하지 않습니다.

- [현재 시즌 HTML 일정표](output/graduation-schedule-2026.html): 프로그램을 실행하지 않고 열어볼 저장 사본.
- [과거 GIST 검증표](output/historical-gist-verification-2025.html): 시작 시각 검증 예시이며 현재 판매 시즌이 아님.
- [실제 검증 결과와 한계](docs/VALIDATION.md): 실제 앱·자료원·원문 대조·브라우저 검사와 미검증 범위.

공식 명부는 860개 기관을 등록했지만 광주 전체 확보를 뜻하지 않습니다. 어린이집·대학 캠퍼스·자료 기준일 등 부족한 범위를 화면에 남깁니다.

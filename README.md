# 광주 졸업식 일정 도우미

학교를 골라 조사를 맡기거나 직접 확인한 내용을 적고, **HTML 일정표 하나**로 결과를 보는 로컬 프로그램입니다. 기록·근거·확인시점·수정 이력은 SQLite에 보관합니다.

## 실행과 사용

이 폴더의 **[start.command](start.command)를 더블 클릭**합니다. 터미널에서는 다음과 같이 실행합니다.

이번 개선을 처음 사용할 때는 현재 실행 중인 기존 앱에서 **저장하고 프로그램 종료**를 누른 뒤 다시 실행하세요. 기존 앱과 실제 DB는 작업 중 그대로 유지했습니다. 다음 실행에서 백업을 만든 뒤 새 저장 구조와 검증 규칙을 적용합니다.

```sh
cd $HOME/workspace/week15/gwangju-graduation-search-agent
.venv/bin/python -m app
```

1. 조사 시즌을 선택합니다. `2026학년도 겨울`은 2026-12-01부터 2027-03-31까지입니다.
2. **조사 맡기기**에서 학교 이름을 검색하고 선택한 뒤 **조사 시작**을 누릅니다. 여러 학교를 선택할 수 있습니다. 현재 표의 학교를 한 번에 다시 선택할 수도 있습니다.
3. 전화나 안내문으로 직접 확인했다면 **직접 확인한 내용**에 적습니다.

   > 건국초 졸업식은 1월 6일 오전 10시, 학교 강당이래. 방금 학교에 전화해서 확인했어. 기록해줘.

   기존 행사가 있으면 그 기록을 보완합니다. 날짜·시각·기관·행사·확인시점이 애매하거나 기존 값과 다를 때만 짧게 묻습니다. 위 문장은 사용 예시이며 실제 건국초 시작 시각을 뜻하지 않습니다.
4. **HTML 열기**로 확인하거나 **HTML 저장**으로 `graduation-schedule-2026.html`을 내려받습니다.
5. **저장하고 프로그램 종료**를 누릅니다. 기록은 남고 진행 중 조사는 멈춥니다.

저장 HTML은 **학교명 | 졸업식 날짜 | 실제 시작 시각 | 학교 위치(주소)**만 보여줍니다. 학교명 검색과 하루/기간 조건을 함께 적용하고 20개씩 이전·다음으로 이동합니다. 이 기능은 파일 안에서 작동하므로 앱이나 인터넷이 필요하지 않습니다. 학교의 공식 링크를 열 때에는 인터넷이 필요합니다.

확인하지 못했거나 현재 사용이 보류된 필드는 `미확인`입니다. 시간이 미확인이어도 정상 날짜는 남습니다. 확인된 취소·미실시는 짧게 표시하고 과거 날짜·시각을 정상 일정으로 보여주지 않습니다. 위치는 학교·캠퍼스의 확인 주소이며 행사장 추정값이 아닙니다.

## 현재 저장 결과와 검증

- [현재 HTML 일정표](output/graduation-schedule-2026.html): 조사 대상 **13기관, 17행**, 날짜 **10건**, 실제 시작 시각 **0건**. 여러 과정이 구분되는 특수학교는 별도 행입니다.
- 학교 주소는 17행 모두 확인되어 있습니다. 공식 링크는 16행입니다. 광주고 부설 방송통신고의 홈페이지는 공식 명부에서 미확인이므로 허위 주소를 넣지 않았습니다.
- 실제 NEIS 전체 기간 조회에서 건국초 **2027-01-06**을 다시 확인했습니다.
- 별도 과거 GIST 공식 공지에서 **2026-02-20 14:00**을 다시 확인했습니다. 현재 시즌 결과에 합치지 않습니다.
- [이번 개선의 검증 결과](docs/IMPROVEMENT_VALIDATION.md), [기계 판독 검사 결과](checks/improvements-results.json).

HTML은 저장 당시의 사본입니다. 최신 정보가 필요하면 앱에서 다시 조사하고 새 HTML을 저장합니다. 모든 광주 기관의 현재 일정을 확보했다는 뜻은 아닙니다.

## 기록·설정

| 위치 | 내용 |
| --- | --- |
| `data/live/graduation.sqlite3` | 실제 기관·행사·근거·수기·자연어 대화·작업 이력 |
| `data/live/backups/` | SQLite 백업. 구조 확장·규칙 변경 전에도 자동 생성 |
| `data/live/exports/` | 앱에서 생성한 HTML 버전 |
| `.env` | 기존 백엔드 선택·키·PC 연결 정보. Git과 출력에서 제외 |
| `config/defaults.json` | 비밀이 아닌 기본 설정 |
| `runtime/improvements-20261020/` | 원본과 분리한 실제 검증 DB·원시 기록 |
| `reference/handoff/` | 변경하지 않은 인계 원본 |

앱의 **기록 관리**에서 백업 저장·새 시즌 만들기·공식 학교 목록 갱신을 사용할 수 있습니다. 설정의 시즌 기본값은 기존 SQLite 시즌을 덮어쓰지 않습니다.

기존 `LLM_BACKEND` 선택과 설정 병합·보호 규칙을 유지합니다. 현재 선택은 Ollama이며 실행 시 준비한 서비스와 모델을 사용합니다. OpenAI를 선택한 경우에만 그 백엔드를 사용하고 장애 시 다른 백엔드로 전환하지 않습니다. 자연어 수기 문장은 로컬에서 처리하며 외부 모델에 보내지 않습니다. 공개 문서의 전송 허용 설정도 그대로 적용합니다.

저장 조회·직접 기록·HTML 저장에는 외부 키가 필요하지 않습니다. 새로운 조사는 준비한 NEIS·검색 키와 선택 백엔드의 연결을 사용합니다. 진행 중 작업의 관련 설정이 바뀌면 이전 작업 재개를 거절합니다. 설치·키 준비 편의 개선은 이번 범위에서 제외했습니다.

자연어 입력은 일반적인 한국어 날짜·시각·전화/문서 확인 표현을 지원합니다. 복잡하거나 지원하지 않는 표현은 질문으로 확인해야 합니다. 이미지·HWP/OCR 및 모든 사이트 형식을 지원하지 않습니다. 실제 전화 확인 사실 자체를 앱이 인증하지는 않습니다.

실제 브라우저에서 앱과 동일 HTML 바이트의 독립 실행을 검증했습니다. 도구의 `file://` 제한 때문에 OS 더블 클릭 동작, 어머니의 실제 PC와 사용성 관찰은 미검증입니다. 새 LLM 모델 정확성이나 모든 기관 원문의 최신 대조도 이번 검증에 포함하지 않습니다.

# 사용자 화면·자동 HTML·개발 검증 분리 검사

2026-10-21. 합의한 변경은 구현했고 실제 사용자 DB의 검증 자료 분리까지 적용했다. 전체 회귀 **547개**, 실제 브라우저 **25개**가 통과했다. 실제 외부 조회는 격리 DB의 첨단고 한 학교이며, 전체 과거 시즌 수집으로 계산하지 않는다.

## 변경과 사용

- `start.command`로 앱을 연다. 새로 보기와 중복 기간 문구를 제거하고, 기록 변경은 자동으로 조회한다.
- 조사·확정한 직접 기록은 SQLite에 자동 저장한다. 앱 실행 중에는 기간별 최신 HTML도 자동 갱신한다.
- **일정표 열기**는 최신 파일을 확인하고, **파일 내려받기**는 별도 복사본을 만든다. 복사본과 이미 열린 HTML 화면은 저절로 갱신되지 않는다.
- 접힌 **관리**에는 기록 백업과 학교 목록 갱신을 둔다. **프로그램 종료**는 진행 중인 작업을 보존하고 HTML 갱신을 마무리한다.
- 입력창에만 남은 문장은 자동 사실 기록으로 처리하지 않는다. 먼저 기록하거나 지우도록 안내한다.
- 시간 미발견, 자료 접근·읽기 실패, 서비스 오류, 미완료를 구분한다. 전체 조사 종료를 모든 일정 확보로 설명하지 않는다.

현재 사용자 데이터의 최신 독립 파일은 [2026-12-01 ~ 2027-03-31 일정표](../data/live/exports/graduation-schedule-2026-12-01-2027-03-31.html)다. 프로그램을 종료한 뒤에도 열 수 있다.

## GIST 분리와 사용자 데이터 보존

고정 URL 검증의 정확한 시즌·행사·두 관측 ID와 공식 출처를 대조했다. 전체 SQLite 백업의 무결성과 선별 원본 JSON의 재읽기를 확인한 다음 같은 거래에서 운영 근거를 분리한다. 보관 실패·식별 불일치·거래 실패는 운영 변경을 취소한다. 같은 행사에 일반 관측이나 수기가 있으면 독립 기록과 UUID를 유지하고 검증 근거만 분리해 다시 평가한다.

## 정상·실패·경합 검사

최종 코드에서 `.venv/bin/python -m pytest -q -rs`: **547 passed / 21.61초 / skipped 0**.

초기 제한 환경에서는 소켓 검사가 한 건 건너뛰어졌다. 허용된 전용 로컬 소켓으로 해당 검사를 확인하고, 마지막에는 전체 검사를 다시 실행해 건너뛴 항목 없이 통과했다.

주요 반례는 다음과 같다.

- GIST만 분리, 일반 재수집과 같은 문서 ID를 공유한 근거·인원 보존, 수기 보호, 겹친 기간 재유입 방지, 재시작 멱등성.
- 종료 전 HTML 저장 실패, 임시 파일 정리 권한 실패, SQLite 잠금 초과, 같은 파일의 자동·수동 저장 경합.
- 이전 정상 파일 유지와 자동 재시도, 저장 잠금 대기 중 앱 조회 응답, 종료 실패 후 조사 실행 가능 상태 복구.
- 접속 실패를 미발견으로 표시하지 않음. 시간·선택 학교·명부 조회를 전체 조사 완료로 세지 않음.
- 재개할 수 없는 작업은 이어서 조사 대신 이 시즌 다시 조사를 안내.

- 날짜·인원을 응답에 주입하지 않았다. 기대값은 수집 후 대조에만 사용했다.

- 내보내기 버튼이나 API 호출 없이 고정 최신 HTML이 생성됨을 확인했다.
- 사용자 DB와 분리한 폴더에서 실행했고 해당 검사의 결과를 사용자 DB에 옮기지 않았다.

## 실제 브라우저

[브라우저 결과](../runtime/usability-v4/browser-150527/result.json)의 25개 검사가 통과했다.

- 실제 사용자 DB의 **사본 조회 2개**: 새 조작·안내 확인, 별도 과거 일반 시즌에서 GIST 검증값이 표시되지 않음.
- 나머지는 **격리 합성 자료**로 버튼·시간 결과 분기·자동 조회·파일 저장 실패·종료·재시작 상태를 검사했다. 실제 외부 수집 성과가 아니다.
- 내려받기 파일명, 오래된 URL 다운로드 차단, 미기록 문장 보호, 저장 오류 복구, 시간 작업 재개를 확인했다.
- 45행 전체 인쇄에서 관리·조사 UI를 숨겼다. 좁은 화면에서 가로 넘침이 없었다.
- 자동 저장한 파일을 서버 없이 열어 45행·확인 시간과 외부 리소스 0건을 확인했다.
- 스크린샷: [실제 사본 화면](../runtime/usability-v4/browser-150527/real-clone-desktop.png), [좁은 화면](../runtime/usability-v4/browser-150527/simple-mobile.png), [합성 자료 화면](../runtime/usability-v4/browser-150527/simple-desktop.png).

## 남은 범위

- 과거 기간 전체 학교 조사는 이번 변경 작업에서 실행하지 않았다.
- 실제 GIST의 일반 조사 재발견은 이번에 새 네트워크로 검증하지 않았다. 분리와 새 근거 저장 경로는 격리 회귀 검사로 확인했다.
- 이번 실제 정상 조회는 정형 API로 충족돼 모델을 호출하지 않았다. 선택 모델의 최신 연결 성공으로 확대하지 않는다.
- 내려받은 복사본·이전에 만든 HTML은 보존하며 자동 수정하지 않는다. 최신 결과는 앱의 자동 갱신 파일 또는 새로 내려받은 파일로 확인한다.

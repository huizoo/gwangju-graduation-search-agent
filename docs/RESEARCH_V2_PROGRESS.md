# 2026-10-21 조사 Agent 개선 기록

## 우선순위와 범위 변경

이번 사용자 요청이 이전 화면·조사 요구보다 우선한다. 조사·조회 대상은 광주 초등학교·중학교·고등학교·대학교·전문대학이다. 어머니의 졸업식 조사 목적에 맞춰 기존의 유치원·어린이집·특수학교·기타 유형을 기본 대상에서 제외한다. 기존 기관·행사·수기·근거는 삭제하지 않는다. 이 변경 사유는 이 기록에만 남긴다.

이전 결과 1.0의 네 열, 하루/기간 선택, 공지 우선 링크, 조사 요청별 좁은 기본 범위는 결과 2.0으로 대체한다. 원본 `reference/`와 이전 검증 증빙은 보존한다.

## 구현 단계

1. 날짜·인원 `date_count`와 단일 행사 `time` 목적, 5열 결과, 복수 실제 행사일 계약.
2. 정형 수집·학교 경로·한 학교를 입력으로 받는 실제 모델 의사결정 반복.
3. 모델 후보의 행사 연결과 독립 원문 관계 검증, 공통 저장·게시.
4. 전체 공식 학교 목록, 작업·재개, 앱·HTML·필터 결과 전체 인쇄.
5. 정상·반례, 실제 선택 모델·자료원·전용 브라우저 검증과 문서 정합성.

## 출발 상태와 판단

- 적용되는 별도 파일 AGENTS.md는 명시한 상위 경로와 프로젝트에서 발견되지 않았다. 사용자의 Global Working Agreements를 적용한다.
- Git 출발점은 `403d3bf`, 작업 트리는 깨끗했다. `.env`, 사용자 DB, 실행 중인 기존 앱을 변경하지 않는다.
- 기존 조사 계획 노드는 고정 검색어를 실행했다. 모델은 추출만 수행했고, 모델 후보의 행사 키가 null로 강제되어 최종 게시 경로가 막혀 있었다.
- 새 Agent는 관찰 결과마다 다음 행동 하나를 구조화해 제안한다. 실행 관리자는 목적·대상·도구·중복·한도·취소를 검사한다. 정형 날짜와 인원이 충분하면 모델 없이 끝낸다.
- 학교알리미 학년별 재학생 수 API에는 별도 키가 필요하다. 사용자에게 안내한 뒤 키 추가 완료 응답을 받았다. 올해 발급 키는 시군구 파라미터가 필수이므로 학교 소재 구를 전달한다. 별도로 공식 공개 공시 경로에서도 건국초 2026학년도 6학년 188명을 확인했다.
- 범위가 독립적인 자료원·Agent 반복·화면 작업을 나누고 핵심 계약·저장·검증은 통합 관리한다.

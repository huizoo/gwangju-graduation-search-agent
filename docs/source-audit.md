# 저장 원문과 게시값의 독립 대조

2026-10-20에 저장된 실제 응답을 다시 읽어 현재 시즌 날짜 10행(6기관)과 과거 GIST 행사 1건의 게시값을 대조했다. 현재 10행은 모두 원문과 일치하며 시작 시각은 모두 미확인이다. GIST의 2026-02-20 14:00은 과거 2025학년도 행사개요의 일시와 일치한다.

네트워크 재호출과 DB 변경은 하지 않았다. 앱의 추출·승인 함수를 실행하지 않고 저장 JSON의 기관 코드·학년도·날짜·교육과정·학년과 게시값을 독립적으로 비교했다. 이 검사는 캡처 당시 응답과의 일치 증거이며 새 실연동, 최신 일정 재확인, 전체 기관 정확성 증거가 아니다.

## 현재 2026학년도: 날짜 무시드 조사

입력 기록: `seeded_date=false`, `seeded_notice_url=false`, `discovery_mode=blind_window`. 일반 표시와 현재 사용이 허용된 날짜 행만 골랐다. 10행 모두 날짜 전용이며 실제 시작 시각 0건, 판매 준비 완료 0건이다.

각 행의 `AY=2026`, `AA_YMD`, 기관명·코드, 교육과정과 Y로 표시된 대상 학년을 확인했다. 캡처된 NEIS 공식 명부의 기관별 `external_key`·이름과 일정 요청 URL의 코드도 일치했다. NEIS 공식 채널 관계 URL은 F10 전체 명부 조회 주소일 수 있으므로 개별 학교코드가 없는 URL 자체를 결함으로 판정하지 않았다. 광주선광학교의 유치원·초등·중등·고등·전공과는 서로 다른 대상 행으로 남아 있다. NEIS 행 텍스트 10개의 SHA-256을 재계산해 저장 문서 해시와 일치함을 확인했다.

## 과거 2025학년도: URL 지정 검사

`seeded_date=false`, `seeded_notice_url=true`, `current_season_result=false`다. 같은 GIST 공지의 저장 문서 2개에서 아래 역할을 구분했다.

| 원문 구간 | 확인 내용 | 게시 처리 |
|---|---|---|
| `[행사개요]` → `1. 일시` | 2026년 2월 20일(금) 14:00–15:40(예정) | 행사일 2026-02-20, 실제 시작 14:00 |
| `[학위수여 안내]` | 13:30까지 1층 출입구로 입장 | 시작 시각으로 채택하지 않음 |
| `[학위복 대여 및 반납]` | 2월 20일 10:00–17:00 | 시작 시각으로 채택하지 않음 |

두 저장본은 조회수가 달라 원래 응답 해시도 다르지만 행사개요와 입장·가운 구간의 의미값은 같다. 원래 HTML 바이트는 이 감사 입력에 없으므로 HTML 해시를 재계산했다고 주장하지 않는다. 저장된 해시와 실제 검토한 텍스트 segment의 별도 SHA-256을 함께 기록했다.

## 파일과 대조 위치

- [현재 조사 캡처](../runtime/live-app/representative-final.json): `/details/0`부터 `/details/9`의 게시값·관측·문서 원문.
- [과거 GIST 캡처](../runtime/live-app/historical-gist-publication.json): `/details/0/documents/0` 및 `/details/0/documents/1`의 `segments/0/text`.
- [캡처된 NEIS 명부](../runtime/provider-live/neis-registry.json): 대상 6기관의 코드·이름 연결에 사용했다. DB 식별자 테이블을 새로 읽은 것은 아니다.
- [기계 판독 감사 결과](evidence/source-audit.json): 입력 파일 전체 SHA-256, 각 문서 ID/해시, JSON Pointer, 대조 조건, 필요한 원문 인용.

현재 입력 파일 SHA-256: `d9402c0439b28b315cdc7196c169f57da6ebf74cc132395b5ed816a661d3ce4b`.

과거 입력 파일 SHA-256: `ffc3339687068ed0d8540557c9f20eb148bc56917c4f15d1c157df7fae3eeac7`.

기관 코드 대조용 명부 파일 SHA-256: `653c0ef19777fd7cde54717d7413975333d25ca4b8fe45b975d7673f5d30cca1`.

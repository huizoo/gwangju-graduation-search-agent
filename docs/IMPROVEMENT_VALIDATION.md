# 단일 일정표·자연어 기록 개선 검증

검증일: 2026-10-20. 이번 사용자 요청을 이전 화면 요구보다 우선했다. 내부 계약 4.0과 이력은 유지하고 사용자 결과 계약 1.0을 추가했다. `reference/handoff`는 수정하지 않았다.

## 구현 결과

앱과 저장 HTML은 학교명·졸업식 날짜·실제 시작 시각·학교 주소의 같은 결과를 사용한다. 현재 출력이 허용되는 필드만 제공하고 나머지는 미확인으로 표시한다. 조사 대상의 미발견 기관도 같은 표에 남는다. 검색과 하루/기간 조건을 함께 적용하고 필터 후 20행씩 보여준다. 학교명은 공식 읽기 페이지 또는 홈페이지에 연결하며 API 주소는 내부 근거로만 남긴다.

자연어 입력은 원문·정규값·질문과 답변·실제 확인시점·수정 이력을 저장한다. 직접 확인과 추측·조사 요청을 구분하고 기존 행사에 시각을 보완한다. 로컬 패턴으로 처리하므로 수기 내용은 외부 모델로 전송하지 않는다. 지원하지 않는 표현이나 충돌은 추가 질문이 필요하다.

| R4: 수기 입력의 중복 생성 | 기존 UUID를 보완한다. 원문·정규값·수정 이력, 재전송 멱등성, 오전/오후 질문, 잘못된 날짜·시즌, 추측·조사 요청, 확인시점 누락·충돌을 검사한다. |
| R5: 이전 HTML의 확인 목록 누락 | 최신 요청이 이전 별도 목록 요구를 대체한다. 요청 기관을 같은 표에 포함하고 미확인 칸으로 제공한다. 판매 구분과 검증 메타데이터를 제거한다. |
| R6: 실행 중 다른 작업 재개 | 생성과 재개에 같은 원자적 활성 작업 검사를 적용한다. 제공자 초기화 전에 거절하며 같은 기관의 동시 조사를 허용하지 않는다. |

관련 검사는 `test_review_regressions.py`, `test_results.py`, `test_natural.py`, `test_experience_migration.py`와 기존 Publication·API·작업·수기·출력 검사에 있다. 기존 설정 병합·선택 백엔드만 초기화·자동 전환 금지·외부 전송·재개 설정 보호 검사도 유지했다.

브라우저 첫 실행은 390px에서 내용 폭이 412px로 넘쳐 실패했다. 입력 패널의 최소 폭을 수정한 뒤 390px/390px로 통과했다. 실제 링크 검사에서는 기존 명부의 null을 `https://None`으로 만든 오류를 발견했다. 명부 정규화, 기존 잘못된 링크의 백업·감사 이력을 남기는 정리, 출력 방어를 함께 수정했다.

## 브라우저에서 확인한 동작

- 실제 저장 데이터의 네 열, 17행·정상 날짜와 미확인 시각, 공식 링크 16개. API·JSON·XML·허위 호스트 링크는 없다. 모든 홈페이지의 현재 HTTP 가용성을 검사한 것은 아니다.
- 실제 앱에서 자연어 문장을 입력해 복사본의 건국초 기존 행사 UUID를 유지하며 시각을 보완했다. 학교 강당은 내부 장소에 남고 결과 주소는 학교 주소다. **여기서 입력한 10시는 합성 검사값이며 실제 사실이나 최종 HTML에 포함하지 않았다.**
- 별도 가상 시즌 45기관에서 기본 20행, 검색+하루 조건 25건의 20/5 페이지, 조건 변경 후 첫 페이지, 빈 결과를 확인했다.
- HTML 저장 버튼과 조사 요청 버튼을 실제 화면에서 실행했다. 조사 버튼은 격리 실행기를 사용했으므로 외부 조사 성공 증빙으로 계산하지 않는다.
- 앱 서버를 종료한 뒤 저장 HTML과 **동일한 바이트**를 실행했다. 기간 조건 43건의 20/20/3 페이지, 외부 리소스 요청 0건, 모바일 넘침 없음을 확인했다.
- 최종 `output/graduation-schedule-2026.html`은 브라우저에서 확인한 원본 결과 HTML과 바이트가 같다. SHA-256은 검사 요약에 기록했다.

전용 브라우저는 `exact-close`로 종료했고 잔여 프로세스는 0이다. 이 작업이 시작한 검증 서버도 종료했다. 기존 사용자의 앱 프로세스는 유지했다.

## 실제 일정과 최종 파일

현재 시즌 결과는 최근 취소되지 않은 13기관 조사와 직접 기록한 기관을 기준으로 한다. 뒤에 취소된 847기관 요청이 이전 결과를 덮어쓰지 않으며 그 작업 자체는 보존했다.

| 항목 | 현재 결과 |
| --- | --- |
| 대상·행 | 13기관, 17행 |
| 현재 허용 날짜 | 6기관의 10행 |
| 현재 허용 실제 시작 시각 | 0행 |
| 확인된 학교 주소 | 17행 |
| 공식 사용자 링크 | 16행. 광주고등학교부설방송통신고등학교는 공식 명부 홈페이지가 없어 일반 텍스트 |

[최종 HTML](../output/graduation-schedule-2026.html)은 저장된 원문을 새 규칙으로 평가한 결과다. 모든 기관의 원문을 오늘 새로 읽은 것으로 주장하지 않는다.

이번 실제 재조회에서는 건국초의 전체 조사 기간을 NEIS에 요청하고 **2027-01-06, 실제 시각 미확인**을 확인했다. 날짜를 요청값으로 주입하지 않았다. 별도 2025학년도 시즌의 GIST는 저장된 공식 공지 URL을 지정해 **2026-02-20 14:00**을 확인했다. 후자는 과거 공지 검증이며 현재 시즌 발견 성과가 아니다.

두 건 모두 실제 읽기 MCP→원문→등록 규칙 1.2.0→격리 SQLite→실제 앱 API→HTML 경로를 거쳤다. 이 재검증에서는 LLM 호출이 0회이며 선택하지 않은 OpenAI를 초기화하지 않았다.

## 적용 상태와 남은 한계

- **코드와 HTML은 완료했다. 실제 DB 적용은 기존 앱 종료 후 다음 실행 시 수행한다.** 이미 실행 중인 앱을 강제로 종료하거나 원본 DB를 변경하지 않았다. 실제 런처의 자동 백업·확장·원문 재평가는 동일 DB 복사본에서 검증했다.
- 기존 `.env`, 비밀값, 수기 기록, 원문 근거, 원본 인계는 보존했다. 설치나 키 준비 변경은 이번 범위가 아니다.
- 도구가 `file://` 이동을 거절해 OS 더블 클릭은 미검증이다. 앱 종료 후 동일 바이트 실행과 외부 리소스 요청 0건을 확인했지만 OS 네트워크 스위치를 끄는 검사는 하지 않았다.
- 어머니의 실제 PC와 사용성 관찰, 모든 기관의 최신 원문 대조, 새로운 LLM 정확성·미선택 OpenAI 접속은 미검증이다.
- 자연어는 일반적인 한국어 확인 표현을 지원한다. 범용 언어 이해, 이미지·HWP/OCR 및 모든 사이트 형식은 지원하지 않는다. 전화 확인 사실 자체를 독립 인증하지 않는다.
- 현재 시즌 시작 시각과 누락된 공식 홈페이지는 추가 확인이 필요하다. 모호하거나 잘못된 값을 채우지 않았다.

재실행 스크립트는 `scripts/verify_improved_ui.py`와 `scripts/verify_improved_sources.py`다. 전자는 이 Mac의 전용 브라우저 도구, 후자는 기존 실제 연결 설정을 사용하며 둘 다 원본 DB의 복사본에만 저장한다.

# 단일 사용자 결과 계약 1.0

이번 사용자 요청은 원본 인계의 일반/판매 구분과 과거 경고 표시보다 우선한다.

- `/api/results?season_id=…`와 HTML은 `app/results.py`의 같은 현재 허용 projection을 사용한다.
- 최근 해당 시즌의 취소되지 않은 조사 요청에 고정된 기관과 직접 기록한 기관이 대상이다. 취소 요청은 새 결과 범위로 덮어쓰지 않으며, 다른 요청이 전혀 없을 때만 최근 취소 요청의 대상을 사용한다. 아직 일정이 없는 기관도 같은 표에 남긴다. 조사가 없으면 기록한 행사 기관을 대상으로 한다. 취소된 작업의 자료와 기록은 삭제하지 않는다.
- 날짜·시각은 내부 Publication의 `current_allowed`를 만족할 때만 출력한다. 시간만 보류되면 날짜는 유지한다. 과거 `general_visible`은 내부 이력 호환용이며 새 사용자 화면의 표시 권한이 아니다.
- 현재 확인된 취소/미실시는 학교 옆에 짧게 표시하고 날짜·시각은 비운다.
- 주소는 공식 명부의 확인 주소이며 장소 필드와 무관하다. 근거를 상속할 수 없는 수기 프로필 주소는 미확인이다.
- 학교 링크는 공식 관계가 확인된 HTML 근거를 우선하고 공식 홈페이지로 대체한다. API·XML·JSON 링크, 인증정보, 사적 메모는 출력하지 않는다.
- 네 열의 단일 표, 독립된 학교명·날짜 조건, 하루/기간 선택, 필터 후 20개 페이지, 날짜/시간 정렬과 날짜 미확인 마지막 순서를 적용한다.
- CSS와 JS는 파일 안에 들어가며 필터·페이지에 네트워크 요청이 없다. 원문 링크를 누르는 동작에만 인터넷이 필요하다.
- 내부 저장·검증 계약 4.0과 별도로 표현 계약 1.0을 둔다. 과거 HTML 파일은 보존하되 표식이 없는 파일을 현재 결과 URL에서 제공하지 않는다.

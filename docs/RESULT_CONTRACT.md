# 사용자 결과 계약 2.0

2026-10-21 요구사항을 현재 결과의 기준으로 삼는다. 원본 참고 자료와 내부 저장·검증 계약 4.0은 보존한다. `/api/results?season_id=…`와 저장 HTML은 `app/results.py`의 같은 현재 허용 결과를 사용한다.

## 범위와 값

- 대상은 공식 목록에 등록된 광주 초등학교·중학교·고등학교·대학교·전문대학이다. 기본 날짜·인원 조사와 표의 표시 필터는 별개다. 구·학교명·날짜·현재 페이지가 기본 전체 조사 범위를 바꾸지 않는다.
- 날짜·시간은 내부 Publication의 `current_allowed`를 만족하는 값만 제공한다. 과거 `general_visible`이나 `sales_ready`는 사용자 표시 권한이 아니다.
- 인원은 해당 학년도 초등 6학년 또는 중고등 3학년 재학생 수, 대학의 해당 대표 본식 졸업자 수다. 근거를 다시 검사하고 유효한 서로 다른 값이 충돌하면 공란으로 둔다. 확인된 0명은 0으로 표시한다.
- 정상 날짜는 시간·인원이 보류돼도 유지한다. 날짜가 바뀌면 이전 날짜에 연결한 시간을 자동으로 옮기지 않는다.
- 현재 확인된 취소·미실시는 학교명 옆에 짧게 표시하고 정상 일정처럼 날짜·시간을 제공하지 않는다. 연기로 개최 일정이 불확실하면 기존 날짜·시간을 보류한다.
- 학교·캠퍼스의 대표 행사가 실제로 다르면 별도 행을 유지한다. 같은 대표 행사의 학부·대학원 대상 표기만으로 행을 나누지 않는다.
- 주소는 공식 명부에서 확인한 학교·캠퍼스 주소다. 장소 메모를 주소로 대체하지 않으며 확인 근거가 없는 프로필 수정 주소는 제공하지 않는다.
- 학교명 링크는 **확인된 공식 홈페이지만** 사용한다. 공지 원문이나 API·XML·JSON 주소를 대신 연결하지 않는다. 홈페이지가 없으면 일반 텍스트다.
- 원문 근거·정책·확인시점·인원 기준·수정 이력은 내부 DB에 남긴다. 사용자 결과에 사적 메모나 검증 상세를 싣지 않는다.

## 행 구조

| 필드 | 의미 |
| --- | --- |
| `institution_id`, `event_ids` | 정확한 학교·행사 연결. 시간 조사는 단일 현재 행사 UUID가 필요하다 |
| `name`, `event_label` | 학교명과 실제 구분이 필요한 대표 행사 설명 |
| `date` | 현재 허용 행사일의 첫 날짜. 미확인 `null` |
| `dates` | 같은 본식이 실제 열리는 날짜 모두. 공란일 때 빈 배열 |
| `start_time` | 현재 날짜에 연결된 실제 본식 시작 시각. 미확인 `null` |
| `graduation_count` | 현재 허용 정수 인원. 미확인 `null` |
| `address`, `district` | 확인한 학교 주소와 표시용 구 |
| `url` | 공식 홈페이지 또는 `null` |
| `status` | 현재 확인한 취소·미실시 또는 `null` |

표의 열 순서는 **날짜 | 학교명 | 시간 | 졸업인원수 | 장소**다. 값이 없으면 `미확인` 문구 대신 해당 칸을 비운다.

## 필터·페이지·인쇄

학교명 검색, 구 선택, 하루 날짜 선택을 독립 입력으로 제공하고 세 조건을 AND로 적용한다. 날짜는 `dates` 중 하나라도 선택일과 같으면 일치한다. 조건을 바꾸거나 전체 보기를 누르면 첫 페이지로 이동한다. 날짜·시간순으로 정렬하고 날짜 공란을 마지막에 둔다. 필터 결과를 화면에서 20행씩 표시한다.

날짜 색은 첫 행사일 문자열의 결정적 값으로 계산한다. 동일 날짜는 구·검색·페이지 변경과 무관하게 같은 색이며 복수 날짜는 첫 행사일 기준으로 묶는다. 날짜마다 본문에 날짜를 표시하고 인쇄에서는 그룹 경계선을 유지하므로 색이 없어도 구분할 수 있다.

인쇄는 **현재 필터를 통과한 전체 행**을 대상으로 한다. 페이지 때문에 숨긴 행은 인쇄 때 다시 보이고, 필터에서 제외한 행은 인쇄하지 않는다. 표 외 제목·검색창·버튼·페이지 조작을 숨긴다. 시간 찾기 버튼을 숨긴 칸은 공란이다.

앱의 빈 시간 행은 학교·시즌·행사를 지정한 시간 조사로 연결한다. 행사나 날짜를 먼저 확인해야 하면 조사 요청을 보내지 않는다. 저장 HTML에는 서버 조사 버튼이 없으며 CSS·JS를 내장하여 네트워크 없이 필터·페이지 이동·인쇄를 수행한다.

## 내보내기 버전

`<meta name="schedule-presentation" content="2.0">` 표식으로 현재 파일을 식별한다. 이전 HTML 파일은 보존하지만 현재 결과 URL에서 그대로 재사용하지 않는다. 불신 텍스트와 URL 속성을 이스케이프하고 CSP 해시로 내장 코드만 실행한다. HTML은 저장 당시의 결과이며 나중에 DB를 수정해도 이미 저장한 파일을 자동 갱신하지 않는다.

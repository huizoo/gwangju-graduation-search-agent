## 실제 실패와 모델 한계

- 최초 실제 선택 Ollama 실행은 학교알리미 인원 원시행에서 원문에 없는 날짜·시각을 제안했다. 기간·원문 관계 검사로 게시되지 않았다. 검증된 인원 표를 행사 원문으로 재해석하지 않도록 모델에는 학년도별 검증 요약을 전달하도록 수정했다.
- 최종 날짜 범위 구현에서도 선택 Ollama의 실제 초기화·5회 호출과 Tavily 검색 4회를 확인했다. NEIS의 전체 기간 조회는 no_data, 학교 홈페이지는 access_failed였으며 모델의 후속 검색도 공식 근거를 확보하지 못해 기존 기관 한도에서 중단됐다. HTTP 14회, 토큰 10,192, 일정 후보·인원 0개다. 이 실행은 **최종 코드의 실제 모델 연동 확인이며 일정 발견 성공은 아니다**.
- 모델의 내부 설명에 나온 미공개 추정은 승인 사실이나 사용자 결과에 사용하지 않았다. 검색 미발견을 공개되지 않았다는 뜻으로 표시하지 않는다.
- 선택한 Ollama만 사용했으며 OpenAI로 전환하지 않았다. 이번 변경에서 OpenAI의 실제 원격 호출은 다시 검증하지 않았다.

## 남은 한계

실제 자료원과 선택 모델을 사용하는 조사이므로 모든 학교·과거·미래 기간의 발견을 보장하지 않는다. 학교 홈페이지 장애·검색 미발견·지원하지 않는 문법·기관별 한도 때문에 빈칸이 남을 수 있다. 이미지·HWP/OCR, 모든 대학 문맥은 지원하지 않는다. 날짜·학년도·행사 관계가 모호하면 보류한다.

대학 학년도를 날짜로 추정하지 않기 때문에 학년도 없는 정상 날짜의 인원은 공란일 수 있다. 여러 날 행사에서 특정 날짜에만 확인한 수기 시각은 다른 날의 시간으로 전파하지 않는다. UI의 합성 시각 성공은 이번 실제 학교의 시작 시각 발견을 증명하지 않는다.

새 설치 절차나 키 변경은 이번 범위가 아니다. 기존 연결과 `.env`를 사용한다. 사용자 작업을 검증에 섞지 않았으므로 검토 예시의 새 사실을 사용자 DB에 몰래 입력하지 않는다. 실제 사용자 DB의 자동 이관은 다음 정상 앱 실행 때 수행된다.

# 구현 진행 기록

기준: 2026-10-20, 인계 계약·게시 정책 4.0.

## 출발 상태

- 작업 폴더에는 `.env`, `.env.example`, `.gitignore`, `config/`만 있으며 앱 코드와 기존 커밋은 없다.
- 상위와 작업 폴더의 추가 AGENTS.md 파일은 발견되지 않았다. 사용자가 제공한 Global Working Agreements를 적용한다.
- 원본 인계 자료와 주석 기준은 `reference/`에 복사했다. 원본 폴더를 수정하지 않는다.
- 기존 설정·비밀값을 보존하며 비밀값을 읽어 출력하거나 추적하지 않는다.

## 구현 단위

1. 사양 검사, 설정 로더, 비밀 분리, 환경 준비.
2. 계약 모델·SQLite·단일 Publication·수기 보호.
3. 실제 자료원·규칙·기관별 조사·공식 목록 적재.
4. 고정 작업 큐·누적 예산·재개/취소·런처·API.
5. 사용자 화면·snapshot HTML·오프라인 검증.
6. 정상/반례·실제 자료원 및 실제 앱 종단 검증, 사용 안내.

각 단위는 검사 후 관련 파일만 로컬 커밋한다. 진행 중인 작업을 완료로 표기하지 않으며 실제 연결 증거와 고정 자료 검사를 구분한다.

## 설계 결정

- 순수 설정 병합 함수는 인계 참조 구현을 `app/configuration.py`로 가져와 런타임 로더에 연결한다. 앱이 검사 모듈을 실행 의존성으로 import하지 않는다.
- API 요청·응답은 4.0 계약을 따른다. 추가 bootstrap endpoint는 실행별 로컬 토큰과 비밀 없는 화면 초기화 정보만 제공한다.
- SQLite는 `data/live/`와 `data/demo/`로 분리한다. 기본 데이터 경로와 앱 자산은 분리한다.
- 네트워크 없이 저장 조회·직접 입력을 사용할 수 있도록 provider 연결은 필요할 때만 초기화한다.

# 구현 진행 기록

**현재 기록:** 2026-10-21의 조사 Agent·인원·결과 2.0 변경은 [진행 기록](RESEARCH_V2_PROGRESS.md)과 [검증 기록](RESEARCH_V2_VALIDATION.md)을 따른다. 아래는 이전 P0 개발의 역사 기록이다.

기준: 2026-10-20, 인계 계약·게시 정책 4.0.

## 출발 상태

- 작업 폴더에는 `.env`, `.env.example`, `.gitignore`, `config/`만 있으며 앱 코드와 기존 커밋은 없다.
- 상위와 작업 폴더의 추가 AGENTS.md 파일은 발견되지 않았다. 사용자가 제공한 Global Working Agreements를 적용한다.
- 원본 인계 자료와 주석 기준은 `reference/`에 복사했다. 원본 폴더를 수정하지 않는다.
- 기존 설정·비밀값을 보존하며 비밀값을 읽어 출력하거나 추적하지 않는다.

## 구현 단위

1. 사양 검사, 설정 로더, 비밀 분리, 환경 준비.
2. 계약 모델·SQLite·단일 Publication·수기 보호.
3. 실제 자료원·규칙·기관별 조사·공식 목록 적재.
4. 고정 작업 큐·누적 예산·재개/취소·런처·API.
5. 사용자 화면·snapshot HTML·오프라인 검증.
6. 정상/반례·실제 자료원 및 실제 앱 종단 검증, 사용 안내.

각 단위는 검사 후 관련 파일만 로컬 커밋한다. 진행 중인 작업을 완료로 표기하지 않으며 실제 연결 증거와 고정 자료 검사를 구분한다.

## 설계 결정

- 순수 설정 병합 함수는 인계 참조 구현을 `app/configuration.py`로 가져와 런타임 로더에 연결한다. 앱이 검사 모듈을 실행 의존성으로 import하지 않는다.
- API 요청·응답은 4.0 계약을 따른다. 추가 bootstrap endpoint는 실행별 로컬 토큰과 비밀 없는 화면 초기화 정보만 제공한다.
- SQLite는 `data/live/`와 `data/demo/`로 분리한다. 기본 데이터 경로와 앱 자산은 분리한다.
- 네트워크 없이 저장 조회·직접 입력을 사용할 수 있도록 provider 연결은 필요할 때만 초기화한다.

## 인계 사양 보완

- 실제 NEIS 공식 주소에 `전남광주통합특별시`가 사용된다. 명칭만 바꾸고 광주 기존 5구 범위를 유지한다. 실제 원문 및 공식 출처를 별도 자료원 문서에 남긴다.
- 운영 허용 규칙은 `ID@버전` 문자열로 고정한다. 이름만 같고 코드 버전이 바뀌면 자동 활성화하지 않는다.
- 공식 API가 제공한 HTTP 홈페이지 관계를 보존한다. 실제 읽기에서는 같은 host/path의 HTTPS 전환과 TLS 성공을 확인하며 다른 host 리디렉트를 공식 문서로 승인하지 않는다.
- 동일 지원 원문 본문이 바뀌었지만 새 값 근거가 없으면 과거 확인값은 보존하고 현재 사용을 보류한다. 실패→성공→실패에서도 마지막 실패를 적용한다.
- export는 새 불변 파일을 만든 뒤 DB 포인터를 갱신한다. DB 갱신 실패가 마지막 정상 파일을 덮어쓰지 않게 한다.
- 학사력 변경 규칙은 이전값·새값·같은 회차·대상을 원문에서 확인한 날짜 관계만 적용한다. 최신 수집일이나 모델 동의로 기존 값을 교체하지 않는다.
- 취득 원본은 해시 일치를 위해 Git에서 binary 속성을 사용한다. 원본의 인코딩·개행·공백을 고치지 않으며 개발 코드의 공백 검사는 계속 수행한다.
- 원본 인계 자료는 수정하지 않는다. 실제 구현의 보완은 프로젝트 코드·문서·회귀 검사에 적용한다.

## 다음 세션의 시작점

1. `README.md`, `docs/VALIDATION.md`, `docs/ARCHITECTURE.md`를 읽고 `git status`를 확인한다.
2. `.env`의 비밀을 출력하지 않고 `start.command` 또는 `.venv/bin/python -m app`으로 실행한다.
3. 기존 `data/live/graduation.sqlite3`를 사용한다. 데모 DB·실제 DB·원본 인계를 서로 덮어쓰지 않는다.
4. 추가 조사는 현재 시즌의 미확인 기관과 실제 시작 시각부터 진행한다. HTML은 필요할 때 새로 생성한다.
5. 남은 범위는 전체 명부·공식 관계 최신성, 미공개 시각, 다른 변경 문법, OpenAI 실연동, 실제 사용자 PC/Windows, OCR/HWP, 구DB migration·복원 화면이다. 미완료 범위를 완료 증거로 바꾸지 않는다.

# 사용자 결과와 개발 검증 분리

2026-10-21 합의한 변경을 구현한다. 원본 참고 자료, 사용자 수기, 설정과 비밀값은 보존한다.

## 결정

- GIST 고정 URL 검증은 실제 사용자 조사의 성과가 아니다. 확인된 검증 기록만 백업과 별도 원본 보관 후 운영 데이터에서 분리한다. 같은 기간의 새 조사에는 검증값을 재사용하지 않는다.
- 조사와 확정한 직접 입력은 SQLite에 자동 저장한다. 변경된 시즌의 HTML도 앱이 자동 갱신하며 기간별 고정 파일을 제공한다. 내려받은 복사본은 자동 갱신하지 않는다.
- 새로 보기와 중복 기간 안내를 제거한다. 일정표 열기, 파일 내려받기, 접힌 관리 기능, 프로그램 종료로 조작을 정리한다.
- 시간 미발견과 자료 접근·서비스 실패를 저장 이력으로 구분한다. 전체 조사 전과 일부 조사·작업 종료를 확인값 확보와 혼동하지 않는다.
- 종료할 때 진행 중인 조사를 보존하고 HTML 갱신을 마무리한다. HTML 저장 실패를 성공으로 표시하지 않는다.

## 구현 분담

- 검증 기록 이관·백업·재유입 방지와 전용 검사 스크립트.
- 작업 이력의 사용자 안내 투영.
- 화면과 실제 브라우저 확인.
- HTML 자동 갱신, API 계약, 통합 검사와 사용자 문서.

## 검증 계획

사용자 DB에는 검사 자료를 넣지 않는다. 복제 DB에서 이관의 보존·재실행·수기 보호·겹친 기간·새 실제 경로 저장을 검사한다. HTML 자동 갱신은 조사·직접 입력·재시작·저장 실패를 검사한다. 브라우저는 전용 browser-verification 수명 관리로 앱과 오프라인 HTML을 확인한다. 합성 UI 검사는 실제 외부 수집 성과로 보고하지 않는다.

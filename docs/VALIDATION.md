# P0 구현·검증 결과

검증일: 2026-10-20. 계약·게시 정책 4.0. 실행 환경: 이 Mac의 Python 3.11 가상환경과 전용 Chromium. 원본 인계 74개 파일과 주석 기준 2개 파일은 복사본과 바이트가 일치한다.

**P0 앱 경로는 구현했다. 현재 시즌의 실제 조사에서는 13개 대표 기관 중 6개 기관의 날짜 10건을 제공하며, 실제 시작 시각은 0건이다.** 날짜가 확인된 기관도 판매 준비 목록에는 아직 포함하지 않는다. 별도 과거 시즌의 GIST 공지에서는 실제 시작 14:00을 원문→MCP→서버 규칙→SQLite→API→HTML로 확인했다.

P0 기능 완료, 자료원별 실연동, 전체 명부 확보, 모든 일정의 정확성은 서로 다른 결과다. 전체 명부 확보와 모든 기관의 날짜·시각 확인을 완료했다고 주장하지 않는다.

## 실제 날짜와 시작 시각의 양성

[GIST 2025학년도 학위수여식 공식 공지](https://www.gist.ac.kr/kr/html/sub05/050209.html?mode=V&no=220361&GotoPage=1)에서 **2026-02-20 14:00**, 광주과학기술원 오룡관 대강당을 확인했다. 입장 13:30과 가운 대여 10:00을 실제 시작 시각으로 채택하지 않는다.

이 검사는 사람이 공지 URL을 선정했고 날짜·시각은 원문에서 추출했다. `seeded_notice_url=true`, `seeded_date=false`다. **“2025학년도 과거 공지 검증 (현재 판매 시즌 아님)”**이라는 별도 시즌에 저장했고 현재 시즌의 6기관 실적에 합치지 않는다. 정확한 원문 버전의 해시와 구간은 [원문 감사 JSON](evidence/source-audit.json)에 있다. 조회수 등 본문 변화로 취득 시점별 HTML 해시가 다른 것은 불변 버전으로 남긴다.

추가한 변경 공지 규칙은 [실제 서강대 과거 원문](https://scc.sogang.ac.kr/front/cmsboardview.do?bbsConfigFK=6633&pkid=921120&siteId=lic)의 날짜 변경을 파싱했다. 광주 밖 사례이며 운영 DB에 넣지 않았다. 공식성 미확인 캡처를 공식으로 바꾸지 않았고, 실제 원문 파싱과 합성 자료의 대체 관계 저장 검사는 [별도 결과](evidence/calendar-change-rule.json)에 구분했다. 광주 실제 변경 공지나 시각 변경의 종단 성공으로 주장하지 않는다.

## 저장 HTML과 화면 검증 한계

- [현재 날짜 일정표](../output/graduation-schedule-2026.html): 10행, 판매 준비 필터 0행. 과정별 검색을 포함한 7개 표시·필터 검사 통과.
- [과거 GIST 검증표](../output/historical-gist-verification-2025.html): 1행, 과거 시즌 표시와 14:00 확인. 8개 표시·필터 검사 통과.
- 생성된 파일의 SHA-256과 브라우저에 전달한 바이트가 일치하고, 앱 서버의 종료를 확인했다. 관찰한 외부 요청·JavaScript 예외·콘솔 오류는 0건이다.
- 전용 자동화 런타임이 `file://` 탐색을 차단했다. 이 제한을 우회하거나 사용자 브라우저에 연결하지 않았다. 허용된 `data:` 실행으로 같은 바이트를 검사했으므로 사용자 PC의 파일 더블 클릭 동작은 아직 직접 검증하지 못했다.
- 브라우저의 offline 설정 호출은 성공했지만 `navigator.onLine`이 true여서 네트워크 차단 자체를 독립 확인했다고 주장하지 않는다. 정적 코드와 실제 요청 관찰에서 HTML의 외부 CDN/fetch 의존은 없다.
- 이전 데모 검사에는 수기 입력·판매 필터·악성 문자열 비실행 증빙이 있다. 이전 `offline_file_opened` 보고를 이번 파일 탐색 차단의 성공 근거로 확대하지 않는다.
- 모바일은 페이지·모달의 외부 넘침 없이 표시되지만 표를 좌우로 밀어야 한다. 실제 터치 기기의 손가락 조작은 미시험이다.

모든 전용 브라우저 lease는 `FINISHED`, 정확한 종료, 잔여 프로세스·프로필 0을 확인했다. 사용자의 일반 브라우저에 연결하거나 종료하지 않았다.

## 사용자 준비와 남은 한계

1. 이 PC에서는 [실행 파일](../start.command)을 더블 클릭하거나 `.venv/bin/python -m app`을 실행한다. 준비한 `.env`와 가상환경을 그대로 사용한다.
2. 자동 조사는 인터넷과 유효한 NEIS·Tavily 키가 필요하다. 현재 키의 실제 연결은 확인했으며 비밀값은 문서·HTML·Git에 넣지 않는다.
3. 모델 후보 추출에는 선택된 Ollama 서비스와 `.env`에 지정된 모델이 필요하다. OpenAI를 선택하려면 해당 키·모델 접근과 공개 텍스트 외부 전송 정책을 준비해야 한다. 자동 백엔드 전환은 없다.
4. 실제 시작 시각은 현재 표본 모두 추가 확인이 필요하다. 기관에 확인한 날짜·시각과 **실제 확인 시점**을 직접 입력한다. 모르는 값을 임의로 채우지 않는다.
5. 전체 명부·미공개 일정·이후 변경·모든 공지 문법·모델 일반 정확성은 보장하지 않는다. 저장한 일반 원문은 작업당 우선 3개와 기관 예산 안에서 재확인하므로 전수 재확인도 아니다.
6. 구DB 이관, 자동 복원, 데이터 보존 기간 정리, OCR/HWP, 동적 브라우저 수집, Windows 실행파일·실제 어머니 PC 배포·예약 운영은 미구현 또는 미검증이다. PPT와 Before/After 비교 시스템은 범위에서 제외했다.

새 세션은 [진행 기록](PROGRESS.md), [구조와 선택 이유](ARCHITECTURE.md), 이 문서와 [독립 검토](p0-independent-review.md)를 먼저 읽으면 된다. 원시 실연동 자료와 DB는 이 작업 폴더 안에 보존되지만 Git에는 포함하지 않는다. 로컬 커밋은 구현 단위별로 만들었고 원격 push는 하지 않았다.
